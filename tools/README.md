# أدوات نقل المراجع

البيئة التي يعمل فيها كلود محجوبة عن الإنترنت العام — لا إنستقرام ولا يوتيوب
ولا درايف ولا دروب بوكس. القناة الوحيدة العاملة هي GitHub.

هذان السكربتان يختصران الطريق: يأخذان فيديو مرجعيًا، يبنيان منه نسخة مصغّرة
وورقة تجميع، ويرفعانهما على فرع `assets`.

| النظام | الأمر |
|---|---|
| ماك / لينكس | `./send-ref.sh ~/Downloads/reel.mp4 siyaq-ref` |
| ويندوز | `.\send-ref.ps1 "C:\...\reel.mp4" "siyaq-ref"` |

## المتطلبات

- **ffmpeg** — ماك: `brew install ffmpeg` · ويندوز: `winget install Gyan.FFmpeg`
- **git** مسجّل دخوله على GitHub

## المخرجات

```
refs/<الاسم>/proxy.mp4    عرض 540px، بلا صوت، عادةً 1–3 ميجا
refs/<الاسم>/sheet.jpg    عشرون لقطة في شبكة 4×5
```

ورقة التجميع وحدها تكفي لقراءة الأسلوب: الألوان، التايبوغرافي، التخطيط،
وإيقاع القطع. والنسخة المصغّرة تعطي الحركة والتوقيت.
