# تُدار — «أجّرت شقتك؟» · حلقة من سلسلة أخطاء الملّاك

فيديو عمودي 1080×1920، 60 إطارًا/ث، 31 ثانية. الأسلوب مستوحى من إيقاع «سياق»
وتخطيطها وهدوئها — بلا أي عنصر من هويتهم.

```bash
npx remotion studio                                   # معاينة وتحرير
npx remotion render TudarEjar out/TUDAR_EJAR_SIYAQ_V1.mp4 --crf=20
```

## الملفات

| الملف | الدور |
|---|---|
| `theme.ts` | الألوان والخط والتخطيط. **`brandFont` هو نقطة التبديل الوحيدة للخط** |
| `script.ts` | السكربت والتوقيتات. الكلمة بين `*نجمتين*` تأخذ البرتقالي |
| `Frame.tsx` | التخطيط الثابت: الشعار، اسم السلسلة، منطقة النص، البطاقة |
| `WordLine.tsx` | ظهور الكلمة بكلمة، وخروج الجملة كاملة مرة واحدة |
| `Card.tsx` | الأربعة عشر رسمًا داخل البطاقة |
| `Grain.tsx` | الملمس الحبيبي، SVG مضمّن لا صورة خلفية |

## ما ينقص قبل التسليم النهائي

| الناقص | الأثر | البديل المؤقت |
|---|---|---|
| `voice.mp3` | التوقيتات تقديرية من جدول البرومبت | عند وصوله: استخرج توقيت كل كلمة وضعه في `script.ts` |
| خطوط نور + Alexandria | الخط الحالي IBM Plex Sans Arabic | ضع الملفات في `public/fonts` وغيّر `brandFont` |
| `tudar-logo-primary.svg` | مكان محجوز منقّط أعلى اليمين وفي مشهد 14 | ضعه في `public/` واستبدل المربع بـ `<Img>` |
| لقطات Mixkit | `assets.mixkit.co` محجوب في بيئة البناء | كل المشاهد مرسومة — وهذا أقرب لأسلوب «سياق» أصلًا |
| المؤثرات الصوتية | الفيديو صامت | نقرة مع كل جملة، ورق عند القطع، خبطة عند الختم، تك مع كل ✓، قفل عند المفتاح |

## قواعد مطبّقة

- كل كلمة تظهر بانزلاق 24px وتلاشٍ خلال 0.28 ث بمنحنى easeOutCubic
- الجملة القديمة تخرج كاملة قبل بدء الجديدة — لا تداخل بين جملتين
- الكاميرا داخل البطاقة لا تتوقف في أي لقطة، وتغوص عميقًا في المشاهد 1 و2 و13
- قطع مباشر بين اللقطات، بلا تلاشٍ متقاطع
- لون مميِّز واحد لكل جملة: البرتقالي على الكلمة المهمة فقط
- اهتزاز واحد خفيف عند نزول الختم في المشهد 8، ولا اهتزاز في غيره
- البطاقة ثابتة في مكانها طوال الفيديو، والذي يتغيّر هو محتواها
